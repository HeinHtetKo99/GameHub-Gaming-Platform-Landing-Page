# 🎮 GameHub – Gaming Landing Page

GameHub is a modern, responsive gaming landing page designed to showcase games, features, statistics, and latest news for a gaming platform.  
It focuses on clean UI, smooth animations, and a professional layout suitable for portfolios and junior web developer interviews.

## 🔗 Live Demo
- https://heinhtetko99.github.io/GameHub-Gaming-Platform-Landing-Page/

## ✨ Features
- Fully responsive layout (mobile / tablet / desktop)
- Smooth scroll + section animations
- Clean UI sections: Hero, Games, Features, Stats, News, Footer
- Reusable Bootstrap components + custom styling

## 🛠️ Built With
- HTML5 (Semantic structure)
- CSS3 (Custom styling & animations)
- Bootstrap 5 (Responsive grid & components)
- jQuery (Scroll animations & interactions)
- Font Awesome (Icons)
- Google Fonts (Lato & Montserrat)
